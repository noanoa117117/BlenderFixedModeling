# 髪調整の判断基準

## 優先すること

違和感の優先順位は「大きな毛束の折れ・膨らみ」→「目立つ浮き・大きな貫通」→「毛先の細部」。ごく小さな貫通や毛先の乱れは許容する。完璧な交差ゼロのために自然な毛流れを崩さない。

- 元の髪型の大きな流れと軽いシルエットを残す。
- 服の表面に沿うように見せる。安全距離を取って空中に浮かせない。
- 貫通箇所は、細かな押し出しを何度も重ねる前に、不要な毛先や内側の束を減らす選択肢を使う。
- 切断する場合は端を揃えず、少数の長さ違いの束でつなぐ。
- 頭サイズと前髪の生え際は、明確な問題がない限り維持する。

## NGパターン

- 毛先を守ろうとして輪、膨らみ、急な折れを作る。
- 肩で上向きまたは横向きに鋭く跳ねる。
- 服から一律に大きく離し、髪が空中に浮く。
- 数値上の交差件数だけを追い、開いた服の裾などの誤検出まで変形する。
- 全景だけを見て局所の破綻を見逃す。
- ソリッド表示の板状の見え方だけを理由に束を削りすぎる。

## Computer Useの使いどころ

- シルエット、毛流れ、切断跡、跳ね、隙間の判断。
- 変更箇所を拡大し、同じ場所を前後両側から見る。
- 4〜5方向の固定確認に加え、肩や襟は局所の斜め角度を追加する。
- 大きな毛束の明らかな折れを優先する。小さな尖りや微小な貫通だけを追って修正を繰り返さない。

## 取り消された指示

以前の「右肩前の髪を減らし、後ろ側の量を残す」という指定は、髪型変更後に明示的に取り消されている。現在の判断基準に使わない。
