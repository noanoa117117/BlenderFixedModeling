# Decisions

## 2026-09-18 — スナップショット併用方式

完全なプロシージャル再生成は、既存の商用髪に含まれるUV、ウェイト、マテリアル、片面カード構造を再実装するコストが大きい。現在の品質を失わずフローを早く回すため、確定 `.blend` をローカルの版スナップショットにし、正本スクリプトが髪メッシュデータを冪等に適用する方式を採用した。

Gitには商品データを含む `.blend` を入れない。スクリプト、数値基準、判断理由だけを追跡する。

## 2026-09-18 — GUI編集を許可

髪の跳ねや折れは目で見て直接直した方が速い場合がある。GUI編集を禁止せず、別名保存、複数角度確認、次版への昇格を必須の後処理にする。
